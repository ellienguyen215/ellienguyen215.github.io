Live at https://ellienguyen215.github.io

## Guestbook: approving notes

1. When someone signs the guestbook, it becomes a new **Issue** in this repo (you'll get a GitHub notification).
2. To show it on the website, open the issue and add the **`approved`** label (Labels → approved). It appears on the page within a minute.
3. To hide or remove one, remove the `approved` label, or delete the issue (⋯ → Delete issue).
